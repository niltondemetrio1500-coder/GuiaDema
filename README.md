# GuiaDema

Página estática da VSL Minuto Salud, publicada com GitHub Pages.

## Desenvolvimento local

```bash
pnpm install
pnpm exec vite
```

## Build

```bash
pnpm exec vite build
```

O deploy é realizado automaticamente pelo workflow em `.github/workflows/pages.yml` após cada push na branch `main`.

> A compra e o evento de conversão do Google Ads permanecem configurados no checkout da Hotmart. Esta página contém apenas as tags base do Google Analytics e do Google Ads.
